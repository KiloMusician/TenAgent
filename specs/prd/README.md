# Product Requirements Documents (PRDs)

This directory contains feature specifications and user stories generated by **Product Manager (Role 01)** following client discovery interviews.

## Naming Convention
* `prd-<feature_name>.md` (e.g., `prd-authentication.md`, `prd-payment-gateway.md`).

## Mandatory Sections
1. Executive Summary & Problem Statement
2. In-Scope (MVP) vs Out-of-Scope boundaries
3. User Stories with Gherkin Acceptance Criteria (`Given / When / Then`)
4. Non-Functional Requirements (Latency, offline support, compliance)
