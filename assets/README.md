# Repository Assets

Place your visual assets here for the GitHub `README.md`:
1. `logo.png`: High-resolution logo badge (already included).
2. `dashboard-preview.png`: Screenshot of the TenAgent 2D Virtual Office running at `http://localhost:7777/dashboard/`.

### How to take the screenshot:
1. Run `office.bat` and open `http://localhost:7777/dashboard/` in your browser.
2. Press `Win + Shift + S` (Snipping Tool on Windows) and capture the full dashboard window.
3. Save the image as `dashboard-preview.png` in this `assets/` folder!
